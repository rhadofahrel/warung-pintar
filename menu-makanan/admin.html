💡 Tips Menggunakan Admin Panel

  • Isi semua field dengan tanda (*) sebelum menyimpan menu
  • URL Gambar gunakan link gambar dari situs seperti Unsplash atau Pexels
  • Rating menu berkisar dari 0-5, default 4.5 jika tidak diisi
  • Klik tombol "Edit" di tabel untuk mengubah menu yang sudah ada
  • Data menu disimpan di browser (localStorage), bukan di server
  • Untuk production, integrasi dengan backend dan database MySQL
